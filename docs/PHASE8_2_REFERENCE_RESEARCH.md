# Phase 8.2 Reference Research: External UX & Design System Patterns

Tanggal: 17 November 2026
Branch: `design/phase8-human-centered-refinement`
Tujuan: Mendokumentasikan 6 referensi design system dan pola UX operasional resmi yang benar-benar diperiksa sebagai dasar perancangan Phase 8.2 tanpa menyalin template mentah atau menambah dekorasi generik.

---

## Ringkasan Pengaruh Skill Anti-Slop pada Riset & Seleksi Pola

Lima skill proyek di `.agents/skills/` diverifikasi aktif (`antislop`, `antislop-ui`, `antislop-human`, `antislop-layoutmobile`, `antislop-copywriting`) dan `contrast-check.py --selftest` lulus (`9 reference pairs OK`). Setiap pola eksternal yang diadopsi harus melewati saringan:
1. Mempermudah operator toko nonteknis menemukan aksi utama dalam hitungan detik (`antislop` R-04, `antislop-ui`).
2. Memenuhi standar aksesibilitas WCAG AA `>= 4.5:1` teks dan `>= 3.0:1` batas kontrol input (`antislop-human`).
3. Terbukti adaptif di viewport `360px` hingga `1440px` tanpa horizontal overflow (`antislop-layoutmobile`).
4. Memakai bahasa operasional Indonesia langsung tanpa tanda hubung panjang em-dash (`antislop-copywriting`).
